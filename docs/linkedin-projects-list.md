# Media suggestions for each project

LinkedIn allows up to 4 media items per project. Prioritize:

1. **1 screenshot** of the actual UI or dashboard (sanitize confidential data)
2. **1 architecture diagram** (draw simple boxes-and-arrows in Excalidraw or Miro)
3. **1 result chart** (before/after metric, or ROI curve)
4. **1 external link** — GitHub repo, live URL, or PDF case study

For AI/RAG projects: a short flow diagram (data source → RAG → agent → user) beats screenshots.
For construction: architectural plan snapshot beats photos.
For BI/dashboards: the sanitized Tableau screenshot is king.
